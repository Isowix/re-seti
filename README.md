# RE-SETI

An early-stage independent proposal by Phil Rail: an AI reanalysis of archival radio SETI data.

SETI@home (1999–2020) and later public surveys, including Breakthrough Listen, recorded large radio archives and reported no confirmed technosignature. RE-SETI asks whether today’s methods would change that result, and treats a careful null as a useful product. It is not a discovery claim.

**Status:** review. No organization has been formed, no funding has been raised, and no infrastructure has been built.

RE-SETI is an independent proposal and is not affiliated with or endorsed by UC Berkeley's SETI@home project, Breakthrough Listen, or the SETI Institute.

## This repository

The project page is a static site (`index.html` and `assets/`) published with GitHub Pages from the root of `main`. There is no build step. `.nojekyll` is present so Pages serves the files as they are.

The figures on the page are original drawings. Quantities on those drawings are labeled illustrative unless a public source is linked. The approved proposal text is in `docs/`, unchanged from archive v1.1.
