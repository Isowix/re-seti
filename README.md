# SETI@Home 2

An independent, early-stage proposal by Phil Rail to reanalyze historical radio SETI archives with modern anomaly detection, and, later, volunteer GPU computing.

The scientific question is narrow: given data that was already recorded — the original SETI@home corpus where it is still accessible, and public Breakthrough Listen data — would today’s methods surface candidates that earlier pipelines missed? A published null result would itself be a useful product. Nothing here is a discovery claim.

**Status:** concept and review. No organization has been formed, no funding has been raised, and no infrastructure has been built.

SETI@Home 2 is an independent proposal and is not affiliated with or endorsed by UC Berkeley's SETI@home project, Breakthrough Listen, or the SETI Institute.

## This repository

The project page is a static site (`index.html` and `assets/`) published with GitHub Pages from the root of `main`. There is no build step. `.nojekyll` is present so Pages serves the files as they are.

The page draws its own figures (a spectrogram sketch, the pipeline, a candidate funnel, the architecture, the phase rail, and an injection-test chart). Those figures are illustrative. They are not measurements. Poster images that carried a UC Berkeley SETI@home URL, or a volunteer-GPU count nobody has, are not on the site. Archive posters for architecture, timeline, and funding are behind disclosures, with captions. The funding poster’s dollar figures and named institutions are historical examples from other projects, not commitments to this one.

`docs/` holds a placeholder index and stubs. Replace those files when the rewritten proposal is ready.
